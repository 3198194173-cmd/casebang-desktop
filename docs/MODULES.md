# 功能模块规划

## 第一层：已经建立的基础能力

- 应用壳：Windows 主窗口、导航、状态概览。
- 基础表管理：分别选择“命名-公式”“A条码参考”“国内命名表”，保存路径并检查文件是否存在。
- 任务入口：选择模板、填写系列资料、导入一张产品总图。
- 配置存储：保存基础表与非敏感设置。
- 安全 IPC：统一通道、参数校验、来源验证和错误封装。
- 连接器注册中心：钉钉、企业微信、通用 HTTP 均实现相同接口。

## 第二层：核心业务模块

- `spreadsheet`：已完成三个基础表的 OOXML 读取、11 个模板识别、字段配置生成、精确任务副本、白名单受控写入，以及公式/样式/行列尺寸/普通图片和 WPS 单元格图片的写后验证；下一步加入安全扩行与图片替换。
- `image`：已完成单张排版总图导入、白底对象检测、裁剪框合并、阅读顺序排列、框选移动/缩放/增删、产品分类选择、全系列主图保护和 PNG 安全导出；后续增加视觉分类与图案自动分组。
- `naming`：为代表图生成三个英文候选、中文解释、历史相似名和同系列唯一性校验。
- `coding`：系列代码定位、各产品前缀、PB 共用、ZJBG/ZJQN 共用数字、保留空号、编码占用检查。
- `workflow`：把上述模块组织成可恢复、可重试、可审计的任务步骤。
- `quality`：缺图、错序、重名、重码、公式缺失、模板版本异常和导出前硬性条件。

## 第三层：联网与外部接口

- `DingTalkConnector`：钉钉机器人消息、企业内部应用鉴权、媒体上传和文件消息。
- `WeComConnector`：企业微信群机器人或企业应用文件发送。
- `GenericHttpConnector`：接入内部系统、云盘、ERP 或后续自建接口。
- `FilePublisher`：当平台只支持链接时，先将导出文件发布到受控存储，再发送下载链接。

每个连接器都声明自己的能力，例如“文本消息、直接文件、链接分享”。界面只允许选择当前配置真正支持的操作，避免按钮显示成功但文件未送达。

## 推荐实现顺序

1. 先完成 Excel 模板分析和工作副本输出。
2. 接入单图裁剪工作区。（已完成基础版）
3. 再完成编码引擎与强制质检。
4. 已接入可替换的视觉 AI 提供商接口；默认使用项目独立的 `casebang-vision:1.0`（Ollama 11535 端口），阿里云百炼 `qwen3-vl-flash` 作为联网备用。
5. 最后配置企业凭据并联调钉钉、企业微信文件发送。
