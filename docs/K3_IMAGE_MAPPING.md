# K3 产品图片对应表业务规则

依据：`CASEBANG-K3名称对应产品图片-260904.xlsx`，实际 286 个分表（包含 WPS 内部图片索引表），解压内容约 251 MB。

## 数据关系

K3 是输出基础表，不参与命名避重、编码分配、价格或机型统计。本次新建图片表生成的物料名称是唯一来源，不另行拼接另一套名称。中文对应采用“IP－中文系列名－中文图案名”，缺少中文时对应使用英文，未填写 IP 时省略该段。

K3 中手机壳的名称使用新建图片表的产品级条码名，不按机型展开成多张相同图片。原始表中历史机型文字保留原样。

## 品类去向

- 磁吸背盖：新建“中文系列名#系列码可拆卸图片+名称”，每列上图下物料名称。表名不读取备注（IP）。
- 出镜壳、出彩壳、出片壳：各自新建“中文系列名#系列码产品类别图片+名称”，上图下物料名称。表名不读取备注（IP）。
- 磁吸支架背盖、气囊支架：追加到“圆片材＆气囊支架名字图案对应”，先背盖支架、后气囊支架；每列三行：图片、物料名称、中文对应。
- 无线充：追加到“充电宝名字图案对应”，每个图案占两列两行。左上图片，右上黄色中文对应；左下 CP002 名称，右下 MP16 名称。
- CP006 自带线：追加到“CP006自带线充电宝名字图案对应”，采用三行结构。
- CP01 自带线：对应旧式“自带线充电宝图片+名称”，与 CP006 分开。
- 方片材、卡包支架：对应“方片材名字图案对应”。普通推卡卡包不是卡包支架。
- 挂绳、挂件、背带、侧挂：对应“挂绳类图片+名称”。
- 礼盒：对应“礼盒图片+名称”。
- 奇趣壳：对应“奇趣壳图片+名称”。
- 其他类别（包括普通推卡卡包、镜头膜、Pad/Macbook 等）：有 IP 时归入“其他联名产品图片+名称”，无 IP 时归入“其他产品图片+名称”。这是依据现有分表名设置的默认归档规则。

公共表接着最后一个图片/名称组的右侧空位续填，填满后再换到下一组，不回填更早的空洞。支架按原表宽列范围填写，自带线最多 12 列；无线充每个图案占相邻两列，最多 6 个图案、12 列。已有行高、列宽及历史图片保持原样。质检加载公共分表完整历史数据与图片，并在真实坐标叠加本次写入内容。表名限制为 31 字符；同名新分表增加编号，旧分表不复用。

## 同图双无线充

每个无线充裁图只有一个图案名称和一个 PB 编码。CP002 与 MP16 共用它们，但分别保存价格。

- CP002：默认建议零售价 239，海外零售价 51.99。
- MP16：默认建议零售价 299，海外零售价 63.99，名称追加 `（10000mAh）`。
- 图片表和条码表先排列所有 CP002 图案，再排列所有 MP16 图案。
- 国内命名只收录一次图案，K3 仅绘制一次产品图片。

## 覆盖闭环

基础资料选择 K3 文件 → 读取分表目录和占用行 → 质检显示锁定坐标 → 勾选 K3 覆盖 → 检查源文件版本 → 生成并验证临时副本 → 备份原文件 → 覆盖原路径 → 同一批时间线记录 → 预览和回滚。

K3 未导入时不阻塞原有三表业务；已导入但无法读取时页面明确提示。K3 在质检之后被外部修改，覆盖会要求刷新并重新生成。历史图片、分表和其他内容保留；不自动清理或重排历史数据。
