# CASEBANG 变更记录

本文档按业务改动逐项记录，后续较大改动继续追加日期和编号。

### CB-027 2026-09-21 共享物料总表、69码基底与工作簿时间轴

- 69码起点只扫描已经合并到物料总表的数据；共享系列工作簿内已填写但尚未合并的号码不再抬高基底。每次分析和写入前自动同步中央共享总表，只有中央总表版本变化才会改变号码基底。
- 资料管理支持把本地物料总表建立或更新为组织级中央共享总表、同步中央最新版并通过 WPS 在线编辑；桌面端统一使用下载的中央修订。钉盘同步本轮仅保留后续接入口，不启用外部写入。
- 工作簿记录移除人工“当前进度”下拉，改为进行中、已完成、已作废三类管理；完成和作废均保留文件与审计历史。
- 每个系列工作簿右侧显示最近编辑时间轴，仅展示编辑人、时间以及“软件加工／手动修改”，不暴露具体修改内容。

### CB-026 2026-09-21 下游资料管理与银框标识配对

- 下游新增“资料管理”，集中提供物料总表的选择、搜索、分页预览，预览与共享工作表编码使用同一份总表配置。
- 新增机型两位编码管理，支持新增和修改标准名称、品牌、编码及别名；保存后的字典立即参与下游物料名称解析和编码生成。
- 出镜壳、出彩壳的同图案普通款与银框款自动按 `A0→AC、B0→BC、C0→CC、D0→DC` 配对；历史映射优先，中央占用与冲突校验保持不变，无法可靠配对时仍阻止自动写入。

### CB-025 2026-09-21 下游编码交互与图案预览

- 新建表加工改为“选择共享工作表 → 选择填写内容 → 预览并保存”的顺序，未选择工作表时不提前展示编码操作。
- 物料总表现在同时用于 69 码续号和物料编码图案映射；已有图案复用历史两位标识，新普通图案按未占用的 A0、B0、C0…提出候选。
- 物料编码页按图案集中确认两位标识，并统一用 iPhone 13 Pro（机型码 53）展示完整编码预览；银框或历史冲突仍要求人工确认。
- 新系列建表和系列补产品必须先展示自动识别值，之后才能显式开启图案标识自定义；自定义需填写原因，并由后台再次执行格式、历史映射和系列占用校验，修订事件保存自动值与最终值。
- 产品补机型不开放图案标识自定义；上游导出保留历史物料编码前缀，下游仅按机型字典补齐末两位，避免重新猜测多系列、多图案的标识。

### CB-024 2026-09-21 下游共享工作表自动编码

- 下游工作台直接读取中央共享工作簿最新版本，并显示物料总表、选定年月前缀、最后已用 69 码和本次第一个号码。
- 69 码按 `YYYYMM + 7 位流水` 分配；默认当前年月，允许在写入前改为设计图档所属月份。系统按选定前缀扫描最大已用流水，忽略夹杂的其他号码格式。
- 69 码与物料编码可分别填写或一次完成；已有值不覆盖，含公式、缺名称或规则未确认的行保留并提示。
- 自动写入后建立新的中央工作簿修订，保存编辑账号和时间；可选择保存后立即打开 WPS 在线检查。
- 中央修订写入增加参与人权限、期望版本和期望修订校验，防止两人同时操作时旧版本覆盖新版本。

### CB-023 2026-09-18 缩小共享工作簿与网络分块

- 新建产品表中的裁剪图片按 Excel 实际显示尺寸生成 2× 高清无损 PNG，不再把数千像素的原图直接嵌入百余像素的单元格。
- 相同裁剪图和显示尺寸只写入一个媒体文件，多个单元格复用该图片，避免银框等重复记录成倍扩大工作簿。
- 公网分块进一步降为 64 KB，并允许最多 3 块并行上传，避开当前线路约 4–5 KB/s 时的单块超时和串行等待；服务器最终仍校验整文件 SHA-256。

### CB-022 2026-09-18 分块传输改用兼容 POST

- 当前公网链路对带请求体的 `PUT` 请求持续无响应，因此分块上传改用兼容性更好的 `POST`。
- 单块从 512 KB 下调为 256 KB，并把单块等待时间控制在 Cloudflare 代理上限以内；整文件 SHA-256 校验和自动重试保持不变。

### CB-021 2026-09-18 共享工作簿改用可重试分块上传

- 修复约 15 MB 工作簿经 Cloudflare Tunnel 上传时，单个长请求超过代理等待上限并返回 HTTP 524 的问题。
- 桌面端按 256 KB 分块上传，每块独立确认并最多自动重试三次；服务器全部接收后再合并并校验 SHA-256，文件内容和建档规则不变。
- 未完成的临时分块具有有效期并自动清理；成功建档后立即删除临时数据。

### CB-020 2026-09-18 共享工作簿改为后台直接建立

- 上游最终步骤不再要求“先导出、再导入”；“建立共享工作簿”会在受控临时目录生成新建产品表、上传中央服务并自动清理临时文件。
- 成功后直接提供“打开 WPS 在线编辑”，上下游继续使用同一中央 `file_id` 和修订链。
- “导出本地副本”降为可选备份操作，并明确标注本地修改不会同步至中央工作簿。

## 验收重点

1. 连续两次点击“选择总图”，第二次默认打开第一次图片所在文件夹。
2. 更换产品类别后，条码品类和默认价格随业务规则变化；价格可选预设也可手填。
3. 颜色（材质）可下拉选择，也可输入总表中没有的新值。
4. 第 5 步导出区只出现新建产品表；覆盖区仍可单独勾选 A 条码参考、国内命名表。
