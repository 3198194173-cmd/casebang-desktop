# 印刷图档与图片表 AI 对比项目结构

文档版本：1.0 · 2026-09-22  
状态：项目结构与实施依据；目录直绑和类别/机型选择骨架已进入代码，PDF 预览与 AI 对比接口仍待实现

## 1. 项目目标

在“新建表加工”流程中，完成以下闭环。69 码、物料编码与图档核验是同一工作簿下的独立步骤；图档核验不要求条码表或物料编码表全部可写。

```text
共享工作表
  ├─ 69 码
  ├─ 物料编码
  └─ 选择系列印刷图档目录
  → 选择产品类别目录
  → 选择样本机型目录
  → 解析 PDF 文件名
  → 打开 PDF 单页预览
  → 与图片表中的产品截图进行 AI 图案对比
  → 人工确认
```

系列目录不是固定父目录。每个系列使用自己的钉钉文件夹链接；换系列时重新选择新的系列链接。

## 2. 文件结构与选择规则

用户粘贴的链接指向一个系列目录，例如：

```text
TSUMTSUMSERIES#J7系列-印刷图档
├─ 一体壳
├─ 充电宝
├─ 支架
└─ 可拆卸
   └─ 苹果型号
      └─ 苹果17PROMAX
         ├─ ...#BG00733#CHARACTERCIRCLE.pdf
         ├─ ...#BG00734#BEAR&PALS.pdf
         └─ ...#BG00735#MICKEYSTACK.pdf
```

操作员需要手工选择：

1. 系列根目录：当前共享工作表对应的系列文件夹。
2. 产品类别目录：例如“可拆卸”。
3. 样本机型目录：例如“苹果17PROMAX”。

默认只核验选中的样本机型，不扫描所有机型 PDF。若样本机型缺少共享表中的图案，系统必须提示“样本机型可能不完整”，不能默认为整个系列通过。

## 3. 图片表主数据规则

图片表中的大写字段“图片对应名称（大写）”是 PDF 文件名图案名称的主匹配键。

示例：

| 图片表字段 | 示例值 |
| --- | --- |
| 图片 | 手机壳截图，包含 Character Circle 图案 |
| 图片对应名称 | Character Circle |
| 图片对应名称（大写） | `CHARACTERCIRCLE` |
| 产品编码 | `BG00733` |
| 系列编码 | `J7系列` |

对应 PDF：

```text
可拆卸手机背盖-苹果17PROMAX-透明片材-
TSUMTSUMSERIES#J7系列#BG00733#CHARACTERCIRCLE.pdf
```

解析后应得到：

```json
{
  "series": "TSUMTSUMSERIES#J7系列",
  "productCode": "BG00733",
  "patternKey": "CHARACTERCIRCLE",
  "category": "可拆卸",
  "model": "苹果17PROMAX",
  "material": "透明片材",
  "extension": ".pdf"
}
```

名称比较需要统一大小写、空格、连接符和文件扩展名，但归一化相同只能作为候选匹配，不能代替图片核验。

## 4. 核验分层

### 4.1 第一层：文件名和业务字段匹配

系统先使用以下字段定位候选：

- 系列编码/系列名称
- 产品类别
- 样本机型
- 产品编码
- `图片对应名称（大写）`
- 材质

第一层结果包括：

- PDF 和图片表均存在且字段匹配
- PDF 存在但图片表没有对应行
- 图片表有行但 PDF 缺失
- 名称匹配但产品编码冲突
- 同名存在多个 PDF，需要人工选择

### 4.2 第二层：PDF 图案与图片表截图的视觉匹配

对于第一层找到的每个候选，系统需要取得 PDF 的单页预览图或缩略图，并与图片表对应行的产品截图比较。

AI 比较内容：

- 角色或主体是否相同
- 姿态、道具和构图是否相同
- 图案排列和相互位置是否相同
- 是否只是同系列或同角色但实际图案不同
- 手机壳外框、镜头孔、底色和透视差异是否只是载体差异

AI 不应根据文件名猜测图片，也不能把“角色相同”直接认定为“图案相同”。

## 5. PDF 预览与数据边界

默认不下载整个系列目录，也不批量下载全部 PDF。

允许的数据流：

```text
目录元数据
  → 选定的类别/机型目录
  → 选定 PDF 的单页预览或缩略图
  → 当前图片表行的截图
  → 已配置的视觉 AI
```

如果钉钉只允许浏览器在线查看，不能向应用返回合法的预览图片，则显示“可在线打开，暂不支持自动 AI 核验”，保留人工确认入口。不能通过抓 Cookie、读取私有缓存或伪造 CDN 地址取得 PDF 图像。

## 6. AI 服务设计

项目复用现有视觉 AI 服务，不重新建立一套命名模型：

- 输入一：选定 PDF 页面渲染图。
- 输入二：图片表对应行的产品截图。
- 输入三：文件名解析结果和图片表字段，仅作为结构化上下文。
- 输出：是否同图、置信度、差异原因、模型版本。

AI 输出只能作为建议，必须由操作员确认后写入核验结果。

建议状态：

```text
matched              名称和图案均匹配
name_matched_visual_uncertain  名称匹配但图案不清晰
visual_mismatch      PDF 与图片表图案不一致
missing_pdf          图片表有记录但没有 PDF
missing_reference    PDF 有记录但图片表没有对应图片
preview_unavailable  无法取得合法预览图
manual_confirmed     操作员已人工确认
```

## 7. 新建表加工界面结构

在同一工作簿加工页面新增“印刷图档核验”步骤；界面上与 69 码、物料编码并列，不以物料编码是否全部可写作为进入条件：

1. 系列图档链接输入框。
2. “读取系列目录”按钮。
3. 产品类别文件夹选择器。
4. 样本机型文件夹选择器。
5. PDF 文件列表及文件名解析结果。
6. 图片表匹配结果。
7. PDF 预览区。
8. 图片表截图对比区。
9. AI 识别按钮、置信度和差异说明。
10. 人工确认、驳回、重新选择文件按钮。

建议采用三栏布局：

```text
左：图片表产品截图
中：PDF 单页预览
右：名称解析、AI 结果、人工确认
```

## 8. 后端模块结构

建议拆分为以下模块：

```text
artwork-source-resolver
  解析系列文件夹链接并建立远程目录索引

artwork-folder-selector
  返回类别目录、机型目录和可选 PDF 文件

artwork-filename-parser
  解析系列、类别、机型、产品编码、图案大写名称

artwork-preview-service
  获取选定 PDF 的单页预览/缩略图，禁止整目录下载

artwork-reference-service
  从共享工作表图片页取得图片、名称、编码和图片哈希

artwork-ai-comparator
  调用现有视觉 AI，返回匹配状态、置信度和差异原因

artwork-review-service
  保存人工确认、审核人、时间、文件版本和证据
```

## 9. 建议数据表

### 9.1 `artwork_sources`

保存系列目录索引，不再限制每个用户只有一个 source。建议唯一键为：

```text
organization_id + user_id + node_id
```

### 9.2 `artwork_work_targets`

保存当前共享工作簿使用的系列目录、类别目录和样本机型目录：

```text
work_item_id
series_source_id
category_dentry_id
model_dentry_id
folder_url
bound_at
```

### 9.3 `artwork_comparisons`

保存单个 PDF 与图片表行的核验结果：

```text
work_item_id
material_row_id
pattern_key
pdf_dentry_id
pdf_version
pdf_page
reference_image_hash
preview_image_hash
ai_status
ai_confidence
ai_reason
model
review_status
reviewer_id
reviewed_at
```

## 10. 完成条件

一条物料只有同时满足以下条件，才允许标记为“图档核验完成”：

```text
69 码已完成
+ 物料编码已完成
+ PDF 文件名字段匹配
+ PDF 单页预览可读取
+ PDF 图案与图片表截图经 AI 或人工确认一致
+ 核验结果已保存
```

AI 失败、预览失败、图案不清晰、名称冲突或缺少图片时，必须保持“待处理”，不能自动通过。

## 11. 验收用例

1. 输入 J7 系列目录，选择“可拆卸 → 苹果17PROMAX”。
2. 正确解析 `BG00733#CHARACTERCIRCLE.pdf`。
3. 找到图片表中的 `图片对应名称（大写）=CHARACTERCIRCLE` 和 `BG00733`。
4. PDF 预览与图片表截图显示同一个环形角色图案时，AI 返回匹配建议。
5. 人工确认后，该行变为“已完成”。
6. 将 PDF 替换为同系列其他图案但保留相似名称，AI 必须标记“不一致”或“待确认”。
7. 换成另一个系列链接时，不得复用上一个系列的 PDF 索引。
8. 无法取得 PDF 预览时，不产生整目录下载请求，并显示“待人工在线核验”。
