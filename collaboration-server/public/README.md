# WPS WebOffice browser SDK

`web-office-sdk-solution-v1.1.27.umd.js` is the stable browser SDK published by
WPS WebOffice. It is kept in the service image so the CASEBANG editor bootstrap
does not depend on a third-party CDN being reachable at runtime.

- Version: `1.1.27`
- Official download page: <https://open.wps.cn/documents/app-integration-dev/docs-center/online-preview-edit/web/jssdk>
- Official package: <https://qn.cache.wpscdn.cn/public_open_weboffice/sdk/web-office-sdk-solution-v1.1.27.zip>

Do not edit the minified SDK by hand. Upgrade it only from an official WPS
package and update this file at the same time.
