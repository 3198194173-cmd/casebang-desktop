# 补原有系列文档表格生成（首版）

入口：流程中心或左侧「补原有系列」。总物料表在「基础资料」首要卡片中导入并保存路径；流程中只需导入补齐表、填写目标机型后匹配。

- 出镜壳/出片壳按图案补齐普通、银框两个版本，保留Y等标记，已有对应版本不重复增加；磁吸背盖、奇趣壳等不自动增加银框。新增版本无专用参考记录时沿用另一版本并提示核价；备注直接继承所选总表记录。
- 机型尾部替换，保留括号款式属性；不支持的机型边界进入未匹配，不猜测。
- 编码 + 产品类型 + 款式匹配；无编码时按规范化名称匹配。
- 优先选择与输入原机型完全一致的参考行，否则选择同图案同款式首条记录并提示核对。价格、备注差异不阻止生成；品类、联名IP、中文名称不同仍标记冲突。
- 价格按普通、银框两组设置，Y不另分组；无银框产品仅显示普通组。移除材质修改入口，旧请求中的材质改写也不再执行。每组旁显示目标机型，价格修改同步预览，留空保留参考价格。
- 未匹配及冲突项独立展开，包含来源、输入名称和原因，超过30条分页；已匹配预览40条分页。
- 支持部分导出，按批次分表、系列间空行，并附未匹配明细。69码、物料编码留空。
- 不覆盖任何已有文件，不修改源表；图片不参与识别和输出，避免加载大图。
- 后台线程解析，限制384 MB堆内存、两分钟超时；预览40条分页。

验证：指定示例输入为97条物料（不含顶部型号说明），放宽价格及备注差异后为89条匹配、8条未匹配、0条冲突。机型边界、实际文件匹配、导出回读、防覆盖、统一修改及不修改原分析值测试通过。界面操作及 WPS 最终验收由用户测试。

首版边界：不提供冲突手工选行/编辑；修正或更新输入文件后可重新分析。按所有识别批次导出；导出采用基础九列表格布局，不复制示例模板的所有格式。机型解析只覆盖代码中明确支持的格式，新增品牌/命名需扩展并补测试。
