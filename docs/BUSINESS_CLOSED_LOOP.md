# 表格编码业务闭环设计

## 目标

将“基础资料 → 工作簿预览 → 表格编码流程 → 生成质检 → 选择性导出/覆盖 → 基础资料复核 → 下一次流程”连成一个可重复、可追踪、可回滚的业务闭环。

## 基础表角色

| 基础表 | 流程用途 | 默认策略 | 是否允许业务覆盖 |
| --- | --- | --- | --- |
| 命名-公式 | 产品表模板、公式和产品类别来源 | 只读 | 否 |
| A 条码参考 | 系列代码、各产品类别已使用编码 | 只读导入，确认后更新 | 是 |
| 国内命名表 | 图案英文命名历史库 | 只读导入，确认后更新 | 是 |

新增或删除基础表时，预览器按工作簿实际工作表清单读取，不依赖固定工作表名称。

## 完整预览

1. 基础资料卡片提供“预览数据”入口。
2. 预览器展示工作簿中的全部工作表、已用行列、单元格值和公式结果缓存值。
3. 大工作簿按页读取，切换页码即可访问全部数据，避免一次性加载造成界面卡顿。
4. 原工作簿自带图片默认不读取、不展示。
5. 由 CASEBANG 写入、名称带 `CASEBANG 图片` 标记的图片需要在对应单元格显示。
6. 覆盖成功后关闭旧预览缓存，再次打开时必须读取磁盘上的最新工作簿。

## 选择性导出

导出页允许独立勾选：

- A 条码参考更新表；
- 国内命名更新表；
- 新建产品表。

用户至少选择一项。新建产品表始终另存；A 条码参考和国内命名支持：

- 导出副本；
- 覆盖当前基础表。

## 安全覆盖

覆盖流程必须依次执行：

1. 检查当前基础表路径仍存在且与配置一致；
2. 在临时文件中完成全部 OOXML 写入；
3. 对临时文件执行基础结构检查；
4. 将覆盖前的原文件复制到应用数据目录的版本库；
5. 用临时文件替换基础表；
6. 记录表类型、原路径、备份路径、时间、任务名称和文件名；
7. 刷新基础资料状态和预览。

任一步失败都不得写入覆盖记录；已有备份不得自动删除。

## 覆盖记录与回滚

基础资料页面显示 A 条码参考和国内命名的覆盖历史。每条记录包含：

- 更新时间；
- 任务名称；
- 被覆盖文件；
- 备份文件位置；
- 当前状态（可回滚/已回滚/备份缺失）。

回滚时先为当前文件再生成一份安全备份，然后将选中历史版本恢复到配置中的原路径，并记录回滚时间。命名-公式不提供覆盖和回滚入口。

## 闭环验收

1. 导入三个基础表后，可查看每个工作簿的全部工作表与全部数据页。
2. 进入表格编码流程并完成生成质检。
3. 导出时可以只选一个、两个或三个结果。
4. 选择覆盖 A 条码参考/国内命名后，基础资料立即显示覆盖记录。
5. 再次预览时能看到新增单元格及 CASEBANG 新增图片。
6. 下一次业务流程读取的是覆盖后的最新编码和命名数据。
7. 从覆盖记录执行回滚后，预览和后续流程重新使用历史版本。

## 2026-09-03 交互与性能补充

- 中文系列名改为选填；英文系列名仍为业务主键之一并保持必填。
- 图案排组拖拽到可视区域上下边缘时，排组容器自动滚动，可跨越长组移动到下方组。
- 基础资料不再按页读取。主进程按“文件路径 + 大小 + 修改时间”缓存工作簿结构，每张工作表只解析一次。
- 预览只传输实际包含单元格或 CASEBANG 新增图片的行；空白格式行不创建前端节点，仍保留真实 Excel 行号。
- 前端使用虚拟滚动，只渲染视口附近的数据行；切换工作表后连续滚动查看完整数据。
- 原工作簿图片媒体不载入；只按关系路径读取程序新增且名称以 `CASEBANG 图片` 开头的图片。
- 导出副本区只另存新建产品表；A 条码参考/国内命名表不再要求导出副本，而是在独立的“覆盖基础资料”区域确认后自动备份、原位覆盖并写入历史。
- 基础表覆盖与“新建产品表”的另存目录相互独立：用户已经确认覆盖后，即使取消新建产品表的目录选择，基础表仍会完成备份、覆盖和历史记录，新建产品表则明确标记为跳过。
- 主进程日志必须记录本次选择的工作簿、覆盖开关、实际导出数、实际覆盖数和跳过数；界面同时校验“应覆盖数量 = 实际覆盖数量”，禁止静默成功。
- 05 页面将“导出副本”和“覆盖基础资料”拆成两个独立操作。导出按钮永远传 `overwriteBaseFiles: false` 并选择目录；覆盖按钮只能选择 A 条码参考/国内命名表，永远传 `overwriteBaseFiles: true` 且不打开目录选择器。
- 同一次覆盖操作使用同一个批次编号，在基础资料中显示为一组时间线；时间线名称与新建产品表文件名一致，组内 A 条码参考和国内命名表保留各自的回滚按钮。
- A 条码参考覆盖除结构检查外，还逐个核对计划写入的业务单元格和值；任一值没有实际落盘则整批停止并恢复原文件，不生成成功记录。
- 04 生成质检为每个绿色变更单元格锁定 `targetAddress`。05 的“导出副本”和“覆盖基础资料”只消费这份坐标计划，禁止依据系列名、文件名、图片名或模板内容再次计算写入位置。
