# 生成、质检与导出统一规则

本文件定义第 04 步“生成与质检”和第 05 步“导出”的唯一数据规则。两步必须使用同一份生成计划；预览中的单元格、图片、名称和编码位置即为最终 XLSX 的写入位置。

## A 条码参考

### 系列名对应代码

- 向“系列名对应代码”写入系列代码、英文系列名、中文系列名和全系列主图。
- 主图按该工作表目标图片单元格的实际宽高横向、纵向分别铺满；这是该表的业务特例，不保持原图比例。

### 已使用编码

- 按产品类别列分别处理；一个类别本次只新增 **一格**。
- 该格写入该类别本次分配到的**最后一个产品编码**，格式为 `BG00793/Cats Limited Series#K1系列`。
- 写入位置是该类别列中最后一个有效编码的下一空格；不同类别允许位于不同的行。
- 只有“字母前缀 + 5 位数字”的内容属于有效历史编码。独立的纯数字（例如 `889`、`895`、`900`、`906`）属于历史异常值：在预览中隐藏，并在导出副本中清空，不参与续号和定位。

## 国内命名表（可拆卸+其他）

- 每次新增两行：第一行横向图片，第二行横向英文名称。
- 第一列永远为全系列主图；其下方必须填写系列标识，例如 `Sweet Bear Series#J8系列`。
- 其他列的数量为：**独立图案数 + 图案组数**。
- 图案组只放该组阅读顺序最靠前的一张图片；其名称使用该图案组确认后的英文名称。

## 新建产品表

- 只保留用户选中的模板工作表。
- 全系列主图写入模板第一行的图片位（B1），不新增空白“主图行”，也不显示“图片”文字。
- 产品行按“产品类别顺序 → 该类别内图片阅读顺序”写入，不能按原模板残留样例或图片碰巧的顺序套用。
- 每一条产品记录是一个不可拆分的数据单元：`产品类别 + 图片 + 图案英文名 + 产品编码` 必须来自同一裁图记录。
- 条码名和图档名由该产品记录实时生成，不能保留模板中的旧系列、旧品类、旧产品编码或旧命名。
- 受控写入范围是 A:J；保留原有单元格样式、边框、行高、列宽、合并关系与工作表格式。
- 条码工作表按品类连续分组，固定优先顺序为：单个片材 → 一体壳 → 无线充 → 自带线 → 支架；一个品类全部结束后才能开始下一个品类。
- 需要机型的品类在组内按“机型 → 图案”排列；当前合并机型名称为 `iP18 Pro/17 Pro`、`iP18 Pro Max/17 Pro Max`，完整文本直接拼接到物料名称末尾。

## 图片规则

- 所有输出图片按目标单元格或合并区域实际尺寸等比缩放、居中，不拉伸、不越界。
- 仅“A条码参考 → 系列名对应代码”的全系列主图按目标单元格宽高铺满。
- 新增行必须先设置与预览一致的图片行高，再按最终行列尺寸建立图片锚点；禁止使用创建新行前的默认 20px 行高计算图片尺寸。

## 系列名称翻译

- 中文系列名通过“接口中心”当前模型执行独立中译英，不再从历史表、图片文件名或本地命名字典匹配。
- 翻译结果统一以 `Series` 结尾，完成后允许人工修改；人工修改后不会被后台翻译结果覆盖。
- 国内命名保留原工作表历史图片并追加本次图片；新建产品表移除模板样例图片后仅保留本次主图和产品图。

## 质检门槛

- 只有一张全系列主图。
- 每个产品裁图都有产品类别、英文图案名和有效产品编码。
- 国内命名图片数量等于 `1 + 独立图案数 + 图案组数`。
- A 条码参考每个实际涉及的类别列只增加一格，且该格是该类别最大的新编码。
- 新建产品表的每行条码名中的产品类别和产品编码，必须与该行图片所属裁图一致。
- 预览和导出由同一生成计划驱动；任一质检失败时禁止导出。
